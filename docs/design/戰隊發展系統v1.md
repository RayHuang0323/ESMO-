# 戰隊發展系統 v1

## 定位

戰隊發展是俱樂部層的長期投資系統，不屬於任何單一選手，也不取代選手訓練。選手訓練負責後天能力提升；個人天賦只描述先天特色與既有相容資料；戰隊發展負責效率、備戰資訊、玩法解鎖與資源方向。

## 相容策略

`profileStore` 以 `TeamDevelopmentState.v1` 保存 `availablePoints`、`spentPoints`、`ranks` 與 `updatedAt`。schema v10 載入舊存檔時，只有在沒有 `teamDevelopment` 欄位的情況下，才把舊 `meta.talentPending` 作為一次性初始發展點；`players[].talentPoints`、`players[].talents.ranks`、derived stats、training 與 growthLog 不變。

所有投入先經 pure reducer 驗證節點、前置與點數，再由 Store 寫回；重複投入不產生第二次扣點。effects 由同一份 state 推導，避免 UI 另算一套數字。

## v1 節點

| 分類 | 節點 | 效果 |
| --- | --- | --- |
| 通用 | 訓練流程優化 | 非休息訓練完成天數減 1，最低 1 天 |
| 通用 | 恢復中心 | 未訓練選手每日額外恢復 4 點體力 |
| MOBA | 英雄研究室 | 解鎖 MOBA 研究提示 |
| MOBA | Ban/Pick 情報 | 需英雄研究室，解鎖備戰提示 |
| CS | 地圖研究室 | 解鎖 CS 地圖研究提示 |
| CS | 團隊磨合 | 需地圖研究室，解鎖 CS 備戰提示 |
| 經營 | 球探網絡 | 球探深度完成天數減 1，最低 1 天 |
| 經營 | 青訓資料庫 | 解鎖青訓支援提示 |

所有節點目前單級、每級 1 點；沒有直接 player stat effect。

## UI 責任

首頁入口改為「戰隊發展」，頁面提供通用／MOBA／CS／經營 tabs、可用／已投入點數、主要方向、節點狀態、前置條件與確認投入。個人天賦頁保留為「個人特質」相容檢視，不再提供反覆基礎能力加點。

## 非目標

本 v1 不改 CS 16 項公式、MOBA 核心戰鬥、RNG、roster generation、progress／reward contract、賽季／賽事或大型 Store。研究旗標目前只提供安全的備戰提示；要接入實際玩法需另行建立 evidence 與 verifier。
