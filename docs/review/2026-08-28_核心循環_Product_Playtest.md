## 一、15–30 分鐘的實際玩家流程

以自動化腳本量到的「操作時間」為準（不含人類閱讀與思考）。
括號內是換算成真人節奏的估計。

| # | 站 | 實測 | 玩家看到什麼 |
|---|---|---|---|
| 1 | 開新檔 | — | 第 8 天、第 2 週、$120萬、12.8萬粉絲。首頁有編號的待辦：`!01 處理資金提醒`、`2 處理收件匣`、`1 戰隊發展`，以及 `NEXT ACTIONS 接下來做什麼` |
| 2 | 俱樂部目標 | 3 秒 | 日 3／週 3／季 4；◆ 0；「見習俱樂部」；「10–20 分鐘做得完；日子只有你自己推得動，沒有時限焦慮」 |
| 3 | 招募／球探 | 6 秒 | 40 名新秀、潛力 `???`／`70~79`、`偵查 0/2`、`🔥 競爭中`、`可簽約`／`預算不足` |

| 5 | 快速練習 | **46 秒**（真人看完約 25 分鐘） | 賽前頁 → Ban/Pick → 分路確認 → 戰術 → 比賽 → 結算（MVP／最佳數據／觀看重播） |

若真的看完一場比賽（22–28 分鐘賽內時間），30 分鐘只夠打一場。

## 二、最自然的核心循環是什麼

**訓練 → 推進天數 → 看到數值真的變 → 再指派一堂。**

這是全遊戲唯一一條「承諾 → 代價 → 兌現」三段都對得上的鏈，而且是實測的：

| | |
|---|---|
| 承諾 | 課程卡上寫「精準度 +1.3、反應速度 +1.0」 |
| 代價 | 體力 85 → 70；「訓練期間選手無法操作」；需 2 天 |
| 交接 | 按鈕自己變成 **`⏭️ 推進訓練日（1 人訓練中）`**——遊戲主動告訴你下一步 |
| 兌現 | 推 2 天後 **精準度 72 → 73.3、反應速度 78 → 79**，分毫不差 |

⚠ **注意這不是玩家心中的核心循環，是目前唯一成立的那一條。**
「打比賽變強」那一條在數值上不成立（見下）。

## 三、最卡的三個地方

### 卡點 1：正式賽季在流程裡**不存在**（最嚴重）

連按「前往下一站」六次，跨越三個生涯年度：

```
第 8 天 → 37 → 65 → 〔第 2 年〕1 → 29 → 57 → 〔第 3 年〕1
每一站都是：「目前沒有排定的賽程」
```

賽事中心同時顯示：`第 3 賽季 常規賽 S3 · 第 1/84 天 · 0/35 場`，
四個項目（常規賽、春季站、夏季站、秋季總站）**全部「未開始」且點不動**。

⇒ 玩家推時間**沒有任何東西在前面等他**，唯一確定會發生的是資金下降
（$128萬 → $89.5萬）。整個「巡迴積分／晉級／冠軍」金字塔頂端玩家碰不到。
季目標「常規賽排名進入前 4 · 本季尚未開賽」也因此永遠 0/1。

### 卡點 2：一場比賽的成長分母荒謬

`XP 24 / 1950` ⇒ **約 81 場升一級**。一般對戰每日上限 3 場 ⇒ **27 天升一級**。
名單上「⚔️ +24 XP」是有顯示的，問題不是看不見，是**看見了也沒有意義**。

對照組：一堂訓練 2 天讓精準度 +1.3（可見、可感、可規劃）。
⇒ 玩家會很快學到「要變強就去訓練，比賽只是拿錢」，
而拿錢又沒有出口（見卡點 3 的延伸）。

### 卡點 3：Retention 目標與遊戲自己的節奏**互相抵銷**

實測到的直接矛盾（同一份存檔）：

```
第 8 天：安排一堂訓練 ⇒ 存檔 counters = { "d8:training": 1, ... }
        （UI 指派確實有寫進目標計數，這點沒問題）
訓練需要推進 2 天才完成 ⇒ 現在是第 10 天
第 10 天：日目標已換成另一組，畫面上沒有「安排訓練」那張卡
        可領 0、點數 ◆ 0
```

**遊戲強迫你推進時間才能完成訓練；推進時間必然讓那天的目標獎勵過期。**
同樣的事發生在比賽上：主流程實測第 8 天打完兩場（滿足「今日出賽」），
沒有先領就推到第 44 天 ⇒ 可領 0、點數 ◆ 0，
存檔裡 `d8:match: 2` 還在，但畫面只讀 `d44:*`。

## 四、最有遊戲感的三個地方

1. **訓練中心**——9 堂課、每堂標明預估成長與效率 105%、體力代價、
   「訓練日誌」、按鈕自動變成「推進訓練日」。這是整個產品裡設計密度最高的一頁。
2. **比賽本體與結算頁**——Baron／Dragon 事件、連殺播報、隊友對話
   （「下路 miss，全體退到安全位」）、MVP、最佳數據、**觀看重播**、
   「查看賽後結算 →」。快速練習也保留完整重播，這反而讓練習有了正當理由。
3. **招募／球探的資訊不對稱**——潛力 `???` vs `70~79` vs `83`、`偵查 0/2`、
   `🔥 競爭中`、`預算不足`。這是一個有張力的決策畫面，不是一張表格。

## 六、Retention v1 到底有沒有幫助

**設計對了一半，兌現失敗。**

對的部分（有實據）：
- 目標文案描述的是**玩家本來就會做的事**（打一場、贏一場、偵查一名新秀、
  安排一堂訓練），這是引導不是作業。
- 頁面自己寫「10–20 分鐘做得完；日子只有你自己推得動，沒有時限焦慮」——
  態度正確。
- 首頁只有一個聚合徽章，沒有紅點牆。
- UI 動作**確實**餵得進計數（`d8:training:1` 實測）。

失敗的部分：
- **獎勵拿不到**：日目標每推一天換一組，而遊戲的核心動作（訓練）本身就要求推天數。
- **拿到也沒用**：Club Points 沒有出口。
- 週目標「輪替陣容 0/7 本週讓 7 名不同選手出賽」，開局只有 5 名選手
  ⇒ 這一條在玩家簽下第 6、7 人之前**不可能完成**。它究竟是誘因還是死目標，
  取決於招募的可負擔性（$118萬 vs 預算 $120萬，只買得起一個）——**這是作業感的來源**。

## 七、Club Points 沒出口是否已經影響體驗

**是，而且是雙重的。**
目標頁明說聲望等級「純榮譽展示，不影響戰力」，又寫「距離『職業俱樂部』還差 500 點」；
全頁找不到任何「兌換／商店／可用於」字樣。
更糟的是實測一輪下來根本是 ◆ 0 ——玩家連「累積了一堆卻花不掉」的階段都還沒到，
就先經歷「做完了卻沒拿到」。**先修拿得到，再談花得掉。**

## 八、下一階段建議

### 主推薦：**C. 生涯內容深化**

但第一刀不是做新內容，而是**把已經存在的賽季接上世界時間**：
讓第 1 賽季在生涯年度內真的開賽、產生賽程、讓「下一站」指向一場比賽而不是年度邊界。
理由：
- 這一刀同時修好卡點 1（推時間沒有目的）、卡點 2 的一半
  （官方賽成長 3.0 倍，才有「值得認真打的一場」）、以及季目標永遠 0/1。
- Ranked、Retention v2、Club Points 商店**全部依賴這一層存在**——
  沒有賽季，排位在排什麼？點數在獎勵什麼？
- 賽事中心、巡迴積分、晉級、冠軍 honors、Season Recap 都已經做好了，
  只差沒有人把它排進日曆。這是接線，不是造鎮。

### 第二順位：**D. UI／UX 收斂**

三個具體且便宜的目標：
① 日目標過期前給提示或允許補領（讓卡點 3 消失）；
② CS 新檔預設補上陣容（或把「自動填入」升為主按鈕）；
③ 比賽 XP 的分母或顯示方式二選一調整，讓「打一場」看起來值得。

### 不推薦現在做

- **A. Ranked**：沒有賽季就沒有排位的語意，而且一般對戰目前是唯一內容，
  加上排位只會讓每日 3 場的限制更痛。
- **B. Retention v2**：為一個玩家還拿不到的貨幣蓋商店，是在錯的一端施工。

## 九、CORE_LOOP_READY 判準與結論

判準在 playtest 之前就先立好，避免事後搬龍門。

| | 判準 | 結果 | 依據 |
|---|---|---|---|
| C1 | 無白屏／卡死／錯誤導航／狀態污染 | ✅ | 四輪 playtest，零 page-origin 錯誤 |
| C2 | 首頁 30 秒內找得到唯一下一步 | ✅ | 編號待辦 `!01/2/1` ＋ `NEXT ACTIONS` |
| C3 | 一次循環能在 UI 內閉合 | ✅ | 訓練→推日→對戰→目標，全程不需 reload |
| C4 | 打完一場後遊戲主動指出下一件事 | ⚠️ | 結算頁有「查看賽後結算 →」、訓練有「推進訓練日」；但**回到首頁之後沒有指向下一場** |
| C5 | 有可見的「投入→變強→看得到→想再投入」 | ❌ | 訓練成立；比賽 `XP 24/1950` 不成立 |
| C6 | 15–30 分鐘內有 ≥2 種不同動機來源 | ⚠️ | 實際只有訓練與招募兩種，且招募受預算限制；賽季那一支不存在 |
| C7 | 獎勵有出口 | ❌ | Club Points 零出口，且一輪下來是 ◆ 0 |

**CORE_LOOP_READY = NO**

差距不在技術面（C1–C3 全過，工程品質是好的），
而在**動機面**：遊戲有一條漂亮的訓練循環、一場好看的比賽、一個有張力的招募畫面，
但三者上面缺一個「為了什麼」——那個東西叫賽季，而它已經寫好了，只是沒有被排進日曆。
