# 正式 MOBA 地圖 Blockout v1 報告（MOBA Map Blockout v1）— Milestone D

> 用非工程師也看得懂的方式說明。**本階段只做遊戲拓撲骨架（Blockout），不追求 3A 美術；
> 未動戰鬥模擬、未改任何模擬座標、未改正式 Router。**

## 1. 為什麼前一張 Terrain Sandbox 不是正式 MOBA 地圖

上一階段（Milestone C）的 `terrain_style.glb` 是一塊**峽谷／瀑布地形**，用來驗證「環境
美術與石頭放置技術」。它**沒有 MOBA 的遊戲結構**：沒有上/中/下三路、沒有雙方基地、沒有
防禦塔、沒有四個野區、沒有龍坑與巴龍坑。它只是一塊漂亮地形，**不是一張能打的 MOBA 戰場**。
本 Milestone D 改為建立**真正符合 ESMO 遊戲結構的地圖骨架**。

## 2. 正式地圖座標來源（唯一真相）

所有結構座標**直接取自 `src/gameData.js`**——這是模擬引擎（`src/LogicEngine.js`）與所有
畫面共用的**單一真相來源**。我們**沒有另建座標系、沒有複製座標、沒有修改任何模擬常數**，
新的地圖只是「照著模擬的座標把骨架畫出來」。

- 地圖範圍：`0–220`（邏輯單位），中心 `(110,110)`。
- 3D 換算：沿用既有 `worldX(x)=(x-110)×1.7`、`worldZ(y)=(y-110)×1.7`（`WORLD_SCALE=1.7`）。

## 4. Simulation → Visual 座標 mapping

- **不新建映射**：沿用 `gameData.js` 既有的 `worldX/worldZ`（純平移＋等比縮放，無旋轉、無
  不對稱）。
- 邏輯 `(x,y)` → 3D `[worldX(x), 高度, worldZ(y)]`（邏輯 y 對應 three.js 的水平 z 軸，
  three.js 的 y 軸留給高度）。封裝在 `src/battle/moba/map/coordinateMapping.js` 的
  `toWorld(x,y,h)`。
- **原則**：地圖配合模擬，不是模擬配合美術。改動任何 BASE/FOUNTAIN/PITS 會破壞
  `check_moba_runtime29` 的對稱 invariant，故一律不碰。

## 5. 使用哪些暫時 Blockout 元件（未來會被替換）

| 元素 | 目前暫時做法 |
|---|---|
| 地面／野區／河道／兵線 | 平面與「帶狀」低模幾何（依折線生成），色塊區分 |
| 基地 | 圓形高地平台＋八面體主堡＋泉水環（發光） |
| 防禦塔 | 低模圓柱標記（依 tier 高矮、依隊伍上色） |
| 龍坑／巴龍坑 | 下凹圓盤＋發光環（龍紫、巴龍琥珀） |
| 營地／草叢 | 小圓錐／半透明圓盤標記 |
| 牆體 | 低矮灰岩塊（InstancedMesh，依 gameData 半徑） |
| 河岸石 | **少量沿用 Rock Pack**（InstancedLODGroup，決定性擺放，示意河岸） |
| 座標標籤 | HTML 疊層（可切換） |

## 6. 哪些資產未來需要替換

- **地形**：正式地形（分塊、材質、河道造型）取代目前平面帶狀 blockout。
- **防禦塔**：正式 Tower Pack 取代圓柱標記。
- **基地／主堡**：正式基地建築與主堡模型。
- **龍／巴龍坑**：正式坑區地形與入口牆體。
- **野區**：Tree/Bush/Ground/Camp Pack 取代圓盤/圓錐標記與牆塊。
- 這些替換都**只需替換渲染元件，不動座標與拓撲**（資料與渲染已分離）。

## 7. 人工目視方式

1. `npm run dev`
2. 瀏覽器開 `http://localhost:5173/?debug=moba-map-blockout`（正式遊戲不加參數不受影響）。
3. **預設打開就是完整俯視**，直接看到整張地圖。底部控制列可切：
   - **視角**：完整／藍方／紅方
   - **圖層**：兵線／野區／塔／龍-巴龍／河岸石／座標
4. 目視確認：第一眼是否像 MOBA 地圖（三路清楚、雙基地清楚、河道分隔、四野區與雙坑清楚、
   不再像單一瀑布地形）、以及是否不卡。

## 8. 下一階段建議

- 若第一眼確實像 MOBA 地圖 → 進入**地形/資產替換**：先做正式地形分塊與 Tower Pack（沿用
  Milestone A/B 的實例化與資產流程），逐步把 blockout 元件換成正式資產，拓撲不變。
- 之後可把此 blockout 的 `layout` 資料接給正式 3D 戰場（`MobaView3D`）作為結構依據，讓
  美術與模擬座標保持一致。
- **本階段不擴充**：不做完整 Tree/Bush/Ground/Tower Pack、不新增大型 benchmark。
