# MOBA 地標強化報告（Landmark Pass v1）— Milestone E

> 用非工程師也看得懂的方式說明。**本次只做低模 Blockout 的「辨識度強化」，不做完整美術包、
> 不做大型 benchmark；未動戰鬥模擬、未改任何模擬座標、未改正式 Router。**

## 1. 本次 Landmark Pass 目標

讓 Milestone D 的地圖骨架，從「有結構」提升到「**第一眼更像 MOBA 地圖**」。重點是
**地標（Landmark）與可讀性（Readability）**：三路、河道、龍/巴龍坑、野區、基地都要一眼認得，
不再像「一堆點和石頭」。手機畫面也要看得懂。

## 2. Milestone D 與 Milestone E 的差異

| 面向 | Milestone D（骨架） | Milestone E（地標強化） |
|---|---|---|
| 三路 | 細窄泥土帶 | **加寬＋深色輪廓底**，路面更亮更清楚 |
| 河道 | 單一青綠帶 | **加寬＋河岸輪廓底＋微發光**，明顯貫穿中心 |
| 龍/巴龍坑 | 一個圓圈 | **馬蹄形坑牆圍住＋兩個入口門柱**，像「坑」 |
| 野區 | 半透明色塊 | 色塊＋**野區入口門柱** |
| 基地 | 平台＋主堡 | 平台＋主堡＋**基地出口門柱** |
| Buff | 只有小圓錐 | **發光 Buff 柱地標** |
| 標籤 | 只有座標 | **區域名稱標籤**（Top/Mid/Bot、Dragon/Baron、Blue/Red Base、四野區、Buff） |

架構不變：`layout` 資料（`mobaMapLayout.js`）與新的 `mapLandmarks.js`（地標資料）都與 render
分離，verifier 可讀；座標仍全部來自 `src/gameData.js`。

## 3. 三路如何變清楚

- 路面**加寬**（帶寬 11→13）並鋪一層**更寬的深色輪廓**在底下（17），形成清楚的路緣。
- 路面顏色改為較亮的泥土色，與草地、野區明顯區隔——**不會被野區石頭或標記淹沒**。
- 每條路中點加上 **Top / Mid / Bot 名稱標籤**。

## 4. 河道如何變清楚

- 河道**加寬**並在底下鋪一層**河岸輪廓**（較深綠），讓「河 zone」與草地、路徑、野區清楚分離。
- 河面微發光的青綠色，一眼知道那是 river，明顯**貫穿地圖中心**（不需要真實水面）。

## 5. Dragon / Baron Pit 如何強化

- 每個坑用**馬蹄形坑牆**（一圈低模灰岩塊）圍住，留下**兩個入口**（面向地圖中心/河道側與其相反
  側）——不再只是一個圓圈。
- 坑底下凹＋發光鏡框，入口處立**兩根發光門柱**（龍紫、巴龍琥珀），一眼看得出「這是坑、入口在
  這裡」。
- 坑上方有 **Dragon / Baron 名稱標籤**。

## 6. 野區與 Buff 區如何標示

- 四個野區象限（藍上/藍下/紅上/紅下）維持色塊，並在**往中心的主要通道口立門柱**，標出**野區
  入口**。
- 每個象限有**名稱標籤**。
- **Buff 區**（藍/紅 Buff）用**發光柱地標**＋名稱標籤標示（不做正式怪物模型）。

## 7. 基地與高地入口如何強化

- 藍/紅基地維持高地平台＋發光主堡（Nexus）＋泉水環。
- 在基地**往地圖中心的出口方向**立**門柱**，標出**基地出口／高地入口**（往三路的出發方向）。
- 基地有 **Blue Base / Red Base 名稱標籤**。

## 8. 哪些仍是暫時 Blockout（未來會替換）

- 地面/野區/河道/三路：仍是低模平面與帶狀色塊（未來換正式地形材質與造型）。
- 塔：仍是低模圓柱標記（未來換 Tower Pack）。
- 坑牆/門柱/Buff 柱/營地：仍是低模幾何標記（未來換正式牆體、坑地形、營地資產）。
- 基地/主堡：仍是平台＋八面體標記（未來換基地建築）。
- 這些替換都**只需換渲染元件，不動座標與拓撲**（資料與渲染已分離）。

## 9. 下一階段建議

- 若第一眼確實更像 MOBA 地圖 → 挑一個區域做「**第一個正式資產替換**」試點（建議先 Tower 或
  基地/坑牆），沿用既有實例化與資產流程，逐步把 blockout 標記換成正式低模資產。
- 之後可把 `layout` + `landmarks` 資料接給正式 3D 戰場作為結構依據，保持美術與模擬座標一致。
- **本階段不擴充**：不做完整 Tree/Bush/Ground/Tower Pack、不新增大型 benchmark。

## 10. 已知限制（Landmark Pass v1 收尾，經目視確認保留）

- **野區仍偏像石頭散佈區**：牆體與石頭已標示邊界，但「由牆體與通道組成的 jungle path 繞行
  感」仍不足，**通道感需下一階段加強**。
- **三路仍是 blockout 色帶**：目前用色塊/平面帶標示路面，**尚未是正式地形材質**。
- **基地與塔仍是暫時 blockout marker**：平台/主堡/塔皆為低模標記，非正式建築模型。
- **下一階段方向**：應進入「**MOBA Terrain Shape Pass**」，強化路、牆、河道、野區通道與
  基地高地的**形狀本身**（讓地形說話），而**不是繼續堆疊標籤/標記**。

## 附註：本輪小幅修正（依目視回饋，形狀優先、少靠標籤）

- **三路**：路面帶大幅加寬（17）＋深色路緣（24）＋亮沙色，底草地調暗 → **不看標籤也知道三條路
  在哪**（中路斜貫中心、上下路沿邊彎、皆連雙基地）。
- **野區**：`gameData` 的 28 道牆體改成**較高深灰岩塊**形成通道與繞行感；石頭改為**附在牆體上**
  （不再散佈河面）→ 讀成「岩壁邊界」。象限加邊界環。
- **龍/巴龍坑**：**下凹坑底＋高坑壁環（馬蹄形）＋入口門柱**；造型分化（**龍＝寬扁六角、巴龍＝
  高尖**）；坑位在河道線上 → 有連河感。
- **基地**：改為**六角高地平台＋疊構主堡＋邊界環＋三路出口門**（往各路方向）→ 不再是平面圓圈。
- **標籤**：保留為次要輔助；地圖形狀本身已能說明位置。

- 目視：`npm run dev` → `http://localhost:<port>/ESMO-/?debug=moba-map-blockout`
  （預設打開即完整俯視；底部控制列可切視角「完整/藍方/紅方」與圖層「兵線/野區/塔/龍-巴龍/
  **地標**/**標籤**/河岸石/座標」）。
- 驗證：`npm run check:mobamap` **165/165**（含三路連通、龍/巴龍存在且不重疊且鏡射、塔數=20、
  四野區、**地標 key 唯一**、**地標皆在界內**、無 NaN、無 Math.random、renderer 不含模擬邏輯、
  取自 gameData）；`npm run build` 通過；`regress` 15/15、`regress2` 8/8（模擬未受影響）。
- FPS/視覺為人工目視（本機無瀏覽器自動化，不虛構）。
