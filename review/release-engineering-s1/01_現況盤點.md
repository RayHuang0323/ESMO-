## 各階段驗收標準（事前定義）

| Phase | 驗收標準 |
|---|---|
| B | 正向案例 PASS；Owner 列的 15 類反向案例全部 FAIL 或 BLOCKED，而且斷言到原因；原收據不變；93655403 的舊收據不能被沿用 |
| C | PID 0、負數、系統行程、未登記、PID 重用、命令列不符全部拒絕，而且不呼叫 kill；真實終止只對自己的無害子行程；沒有依名稱或埠號終止的 API |
| D | 中斷、續跑、竄改、SHA／工具／契約／環境不符都有合成測試；續跑不漏、不重複；per-unit 整組重跑；舊紀錄保留 |
| E | `npm ci` 的依賴樹與 lockfile 完全相同；build 與正式站逐檔相同；部署判斷的反向案例（src／public／依賴／建置設定／CI／前次部署失敗）都會部署 |
| F | 過期收據絕不顯示為 PASS；排序建議可驗證；正式效期不變 |
| G | GO 只在 assert 全部 PASS＋旗標＋指紋＋main 關係都成立時；RUNNING、INTERRUPTED、EXPIRED、NOT_RUN 一律 NO-GO |
| H | 獨立 Code Review；產品輸入 diff 為 0；指紋與旗標不變；build 成功；既有 Release Gate 自我測試 118/118 |
