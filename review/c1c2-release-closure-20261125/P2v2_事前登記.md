## 2. 流程（每次執行）

首頁 → MOBA → 配對 → Ban/Pick → 載入 → 戰鬥 → 1×、2×、4× 各觀看 20 秒 → 快速完成 → 結算 → Replay 三輪（每輪：開啟 → 播 20 秒 → Replay 開著強制 GC → 關閉 → 強制 GC）。

## 3. 樣本與順序

- 暖機：BASE 一次、CAND 一次（種子 30999），**不計入判讀**。
- 正式：3 場比賽 × 4 次 = 12 次。順序：第 1 場 B C C B、第 2 場 C B B C、第 3 場 B C C B。每個 build 6 次。

## 4. 記錄

每次：場次 id、seed、本場設定雜湊、選角序列、比賽總長；瀏覽器版本；快速完成耗時；三段觀看的 rAF 間隔 p50／p95、>50 ms 幀數、long task；全程最高 heap；Replay 前 heap（未 GC 與 GC 後）；每輪 Replay 播放中峰值 heap、20 秒時 heap（未 GC）、開著 GC 後 heap、關閉後 heap（未 GC 與 GC 後）、rAF p50／p95／p99、>50 ms 幀數、long task、CPU（`TaskDuration` 佔比）與 Script 佔比；page error 與 console error。

## 6. 停止規則

- **INVALID（不是 PASS，也不能據此判讀）**：同一個種子的 4 次不是同一場比賽；3 個種子沒有產生 3 場不同的比賽；瀏覽器版本不一致；執行前斷電；BASE 不是 `053fd582` 或任一工作樹不乾淨；建置失敗。INVALID 時停止並回報 Owner，不自行重跑。
- **FAIL**：任何一項門檻不符或產品錯誤。FAIL 時停止後續大型 Release Gate，回報是否有真實產品退步；**不調整門檻、不重跑求 PASS**。
- 沒有 INCONCLUSIVE 或重跑條款：一次執行就是最終結果。
