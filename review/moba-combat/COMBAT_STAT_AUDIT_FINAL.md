## 2.5 本輪新增：apm 量測（情境 `roam`）

### 為什麼選 roam 情境

apm 的正式作用路徑共 **5 條**（其餘出現處為選秀／個性／roster 權重，不經戰鬥接線）。
`roamAdj` 的基準 `roamRate` 在中性情境是 **0** ⇒ 會被下限吃掉、40 與 70 無法區分（§1-C 的單向解鎖）。
`roam` 情境（`roamRate = 0.5`）是**唯一能讓五條路徑同時生效且不觸發 0-clamp** 的情境；
`gankInterval` 在該情境維持 45，其餘三條本來就恆常有效。

### 理論 vs 實測

| 路徑 | 權重 | 理論 40/70/90 | 實測 | 顯著 |
|---|---|---|---|---|
| `gankIntervalScale` | −0.080 | 48.6 / 45.0 / 42.6 秒 | Gank 24.18 / 25.58 / 26.60（**+2.42**）。比值 90/40 實測 1.100 vs 理論 1.141 | ★ |
| `roamAdj` | +0.060 | 0.440 / 0.500 / 0.540 | 遊走／分 0.524 / 0.580 / 0.638。比值 90/40 實測 **1.217** vs 理論 **1.227** | ★ |
| `lastHitLoss` | +0.030（單向） | 罰 0.030 / 0 / 0 | 補刀率 **97.06% / 100% / 100%** ——只有 40 分受罰，與單向設計一致 | ★ |
| `xpRateScale` | +0.015 | 0.985 / 1.000 / 1.010 | 本場等級 9.013 / 9.153 / 9.413（+0.400） | **·** |
| `laneAdj` | +0.015 | −0.015 / 0 / +0.010 | 推塔 30.85 / 32.02 / 31.85（+1.00） | **·** |

**三條達顯著且與理論吻合**（`roamAdj` 的比值誤差僅 0.8%）。

⚠ **兩條低於偵測門檻**：`xpRateScale`（±1%）與 `laneAdj`（±0.015 的推線位移）
兩者的設計幅度本來就極小，30 seeds 量不出來。**這不是接線錯誤，是量測解析度不足**；
若要確認需大幅加樣本，但以其設計幅度而言，實務影響也確實接近可忽略。

### 判定：**A. 接線正確、效果合理**

語意成立：操作速度高 → 補刀不漏兵、Gank 更頻繁、遊走更多。
死亡 −1.57（·）、勝率 +6.1pp（·）皆不顯著，無異常副作用。

⚠ **但 apm 共享了 C 的問題**：遊走接戰率 20.1% / 21.2% / 21.0%（**平的**）——
與 comms 完全相同的形態，量增加而品質不變。
⇒ 這是 `roamAdj` 這個作用點本身的結構問題，不是 apm 的問題。

⚠ **語意疑慮**：`apm`（操作速度）出現在 `roamAdj`（輔助遊走率）在語意上難以成立。

## 3. 三個結構問題（**必須分開處理，不得合併成一次重構**）

### A. Retreat / Push utility（撤退與推進的效用失衡）

**證據鏈（每一段都有 95% CI 不含 0）：**

`retreatAdj` 為正 → 撤退次數↑★ → 作戰持續↓★ → 推塔↓★ → 死亡↓★ → 勝率↓

（相關係數 r(權重, Δ撤退)=0.832、r(權重, Δ推塔)=−0.913），
**不再有任何單項勝率顯著性**。
⚠ 任何引用 A 的文件都必須用這個較弱的說法，不得再寫「勝率單項即達顯著」。

**核心診斷**：早撤**確實兌現了它該有的好處**——死亡顯著下降約 3 次。
問題是引擎**沒有把「少死」轉換成任何優勢**：擊殺（·）、本場等級（·）都沒有顯著改善。
省下 3 條命換掉約 4 次推塔，淨值為負。

再加上分推行為也不轉換成推塔（見 §2），結論是：
**這個引擎裡「留在場上」是唯一有效的推進手段，任何形式的保守（撤退、分推）都拿不到補償。**

**不是權重問題**：調 `retreatAdj` 的大小只會讓效果趨近於零，不會改變符號。
真正要處理的是「存活／經濟優勢 → 推進優勢」的轉換路徑本身。

**受影響素質**：decision（D）、positioning（F，行為已確立）、courage（A，反向受益）、
clutch（B）、resilience（B）——**五項的表現都被同一個機制決定**。

### 為什麼不能合併

三者的**作用層不同、修法不同、風險不同**：

- **A** 動的是經濟／推進的轉換規則（`_dmgGold`、塔傷、等級曲線）⇒ 影響**全部 16 項**與所有既有平衡數據，風險最高。

- **C** 動的是遊走的目標選擇（`:3217-3221`）⇒ 影響面最窄，風險最低。

合併重構會讓三者的效果互相污染，**任何一項回歸都無法歸因**。

## 6. 技術債（C 關閉時遺留，**不在 C 範圍內繼續處理**）

### D-1：comms 的品質區辨力仍不顯著

30 seeds × 鏡像下 comms 40→90 的品質梯度：

⇒ comms 目前在 audit 表中的分類**維持不變**，待 D-2 處理後再重新量測。

### D-2：roam ETA／地圖尺度／可達候選數

候選 ETA **中位數 25 秒、p90 52 秒**，而遊走窗原本只有 8 秒
⇒ 除相鄰那一路外沒有任何可達候選，「目標選擇」的決策空間本身就窄。

可達候選數仍然少，這正是 D-1 的直接成因。

需要獨立處理（可能牽涉移速、地圖尺度或遊走承諾模型），
**與 A、B 皆不同層，不得併入任一方**。
