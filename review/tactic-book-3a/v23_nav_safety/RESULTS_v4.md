## N3 的原因

生涯 100 場的陣亡拆解（`batches/` 的逐筆陣亡紀錄）：

| | v3 | v4 |
|---|---|---|
| 被塔擊殺 | 98 | 123 |
| 其中撤退中 | 94 | 121 |
| 撤退中被英雄擊殺 | 1,272 | 1,290 |
| 總陣亡 | 2,194 | 2,180 |

- 多出來的被塔擊殺全部是撤退中的人。
- v3 把人沿「塔 → 我」推進口袋之後，口袋在射程外。附近沒有敵方英雄時，既有的回城引導會啟動，人就地回城。
- v4 的規則是「出口回不了家就不用它、被包住就穿出去」。它不看口袋安不安靜，一律要人穿過塔的射程回家。殘血的人因此被塔打死。
- v3 的 372 次「退回直線回家」是口袋裡**回城起不來**的情況（有敵方英雄在附近，或回城冷卻中）。真正需要穿出去的只有這一部分。
