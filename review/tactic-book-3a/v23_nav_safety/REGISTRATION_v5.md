| 在口袋裡被危險圓包住，口袋安靜 | 直線回家，一進圓又被推回來 | 走成本最小的穿出路線 | **原地等**（既有回城引導在冷卻結束後接手） |

## 4. 判準（固定，不依結果調整）

與 `REGISTRATION.md` §4 的 N1～N8 相同，分析腳本同一支。只有 N5 改了：

| # | 項目 | 判準 |
|---|---|---|
| N1 | 撤退退回直線回家 | `blockedFallback`：v5 ≤ v3 的 20%（前提 v3 ≥ 20） |
| N1b | 紅藍各自 | 藍、紅各自減少 |
| N2 | 座標合法 | 座標不可走、NaN：v5 皆 0 |
| N3 | 撤退安全沒有變差 | 生涯合併、工具合併各自判定。撤退中被塔打中、撤退中陣亡、被塔擊殺：配對差 95% CI 下界 > 0 且 > +5% ⇒ 變差。撤退成功率：CI 上界 < 0 且 < −5% ⇒ 變差 |

| **N5** | 不製造新的卡住 | 卡住 ≥ 20 秒、30 秒內避塔 ≥ 6 次：**成對差 95% CI 下界 > 0 且總數 > v3 × 1.1 ⇒ 不通過**。塔邊等待 ≥ 20 秒、等待中掉血 ≥ 25%：v5 ≤ v3＋2 |

| N8 | 對局完成 | 沒有未結束的對局 |

N5 為什麼改：原本的「總數 ≤ 1.1 倍」沒有考慮場與場之間的變異。這類事件每場 0～10 次，一場特別長的對局就能讓 40 場的總數差 40%。改成成對檢定之後，要「每場平均確實變多」而且「總數超過一成」才算不通過。這是在看 v5 新 Seeds 的任何結果之前定的。
