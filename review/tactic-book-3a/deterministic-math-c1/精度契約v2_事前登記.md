## 1. v2 精度限制（固定）

誤差＝\|det 結果 − 精確值\| ÷ ulp(精確值)。精確值由 BigInt 定點參考實作計算（`tools/lib/det_math_ref_c1.mjs`：≥ 256 位元；π 以 Störmer 公式獨立計算，並與公開常數的前 65 位十六進位比對）。

| 函式 | 絕對上限（最大誤差） | 理由 |
|---|---|---|
| sin、cos | **< 1 ulp** | fdlibm 核心多項式＋三段 Cody–Waite 化簡的設計精度（文件值 < 1 ulp） |
| asin、acos | **< 1 ulp** | fdlibm 有理近似的設計精度（文件值 < 1 ulp） |
| atan2 | **< 2 ulp** | 演算法先把 y／x 捨入成 double 再求 atan，象限修正時再做一次 π − z。誤差＝atan 本身（< 1 ulp）＋商的捨入造成的相對誤差（≤ 2⁻⁵³，最多約 1 ulp）＋最後一次加減的捨入；理論上界超過 1 ulp。v1 量到 1.393 ulp，與這個分析一致，且與 Node 原生在同一輸入上完全相同 |

兩條相對條件（都要成立）：

| 條件 | 內容 |
|---|---|
| R1 不比原本的模擬差 | 每個函式在 v2 資料上的 det 最大誤差 ≤ Node 原生（過去所有正式統計所用的數學）在同一批資料上的最大誤差 |
| R2 與原生的距離 | 所有 v2 有限值輸入上，det 與 Node 原生的結果相差 ≤ 1 ulp |

只報：Chrome／Firefox／WebKit 原生的誤差（不是判準）。

## 2. 特殊值與邊界的比較方式（固定）

| 類別 | 比較方式 |
|---|---|
| 一般有限值、次正規數 | 64 位元完全相同 |
| ±0 | 依符號比較（`Object.is`）：+0 與 −0 不同 |
| ±∞ | 位元相同 |
| NaN | 依「類別」比較：兩邊都是 NaN 即相同，不比 payload（ECMAScript 不保證 NaN 的位元樣式） |

### 特殊值契約（結果必須完全符合）

| 輸入 | 期望 |
|---|---|
| sin(NaN)、sin(±∞)、cos(NaN)、cos(±∞) | NaN |
| sin(±0) | ±0（保留符號） |
| sin(±5e-324)、sin(±2.2250738585072014e-308) | 輸入本身 |
| cos(±0)、cos(±5e-324) | 1 |
| atan2(±0, +0)、atan2(±0, x > 0) | ±0 |
| atan2(±0, −0)、atan2(±0, x < 0) | ±π |
| atan2(y > 0, ±0)、atan2(y < 0, ±0) | π/2、−π/2 |
| atan2(±y, +∞)、atan2(±y, −∞)（有限 y > 0） | ±0、±π |
| atan2(±∞, +∞)、atan2(±∞, −∞) | ±π/4、±3π/4 |
| atan2(±∞, 有限 x) | ±π/2 |
| atan2(NaN, x)、atan2(y, NaN) | NaN |
| acos(1)、acos(−1)、acos(±0) | +0、π、π/2 |
| asin(±1)、asin(±0) | ±π/2、±0 |
| acos、asin（\|x\| > 1、±∞、NaN） | NaN |
