## 3. C3 任務（每項都要事前登記：指標、方向、seeds、gate）

通用規則（草案 §1.3）：先把「選項 → 指標 → 方向 → 門檻 → seeds 區段」commit 進 git 再開跑；新 seeds、紅藍雙方各量一次；兩側都「方向相符、配對 z ≥ 3、|Δ| ≥ 5%」；責任週期類指標另須「只數開始」版本兩側達標；結果出來後不換指標、不換 seeds、不丟 seed；不放大係數。

### 3.1 C3-1 時期骨架

- 內容：`knobs(side)`／`identity(side)` 在 `t` 跨 480、960 時回傳該時期預先建好的那一份（R-5）；觸發只有時鐘；Resolver 輸出三份（D-13）。
- 事前登記指標：**決定性檢查，不是統計指標**。對每個時期欄位組合，`directive(side, t)` 在 `t` = 479／480、959／960 的差異恰好是宣稱會變的欄位；不跨邊界、未選新維度時，回傳物件與設定物件是**同一參照**（R-4）。
- seeds：不跑模擬（決定性）。
- Gate：G-AC1（含 ③ 同一參照）、G-AC2、G-A2、RS-1（見第 4 節）。

### 3.2 C3-2 時期姿態

- 內容：**不改**姿態的作用欄位與方向（`identity.phaseEngage／phaseJoin`），只換指標重新登記。〔事實〕舊指標（`fightEntriesPerMin.<p>`）屬 C7 類別 4，需要改用接戰決策類指標。
- 事前登記指標：`engageDecisionsPerMin.<p>` ＋ `engageStartsPerMin.<p>`（只數開始，必須）。方向依 Registry rank：前／中期 `defensive < scaling < standard < aggressive`；後期 `defensive < standard < scaling`。
- 前置儀器：〔事實〕這兩個指標今天**不是分時期的**（整場純量，`tacticTruthSim.mjs:77-78, 98`）⇒ 先寫分時期分桶儀器（見 3.4）。
- seeds：**3001–3400**，n＝400／側，紅藍各一次；後期有效配對 n ≥ 200，不足另開區段、經 Owner 核准。
- 對照組：同模板、該時期欄位為 `standard`（或模板原值），只動一個時期的一個欄位。
- Gate：新 seeds 兩側達標；姿態若仍量不到 ⇒ 維持 `MEASURED_EXCLUSIONS`，**不放大** `PHASE_ENGAGE`；是否動用「一次重新設計」（備用區段 7001–7400）是 Owner 決定（D-18）。
- 〔推估〕這是四個勝利條件方向的單點依賴（決策表 §1.2）：不過則前期滾雪球與後期團戰沒有可登記的主指標。

### 3.3 C3-3 時期集結（**被 C7 §4-B 擋住**）

- 內容：`grouping` 為 `group`／`spread` 的時期，Director 讓 `knobs.joinFight` 高於／低於該側整場值；`standard` ＝同一參照；只影響非巨龍、非巴龍坑的熱點。
- 擋住原因：〔事實〕整場 `teamfight.grouping=tight` 只量到 +1.9%（藍）／+3.7%（紅）；在 C7 §4-B 判定擲骰成功次數本身是否動得了之前，**不得登記 `phases.*.grouping`**。
- 事前登記指標（暫定，等 §4-B）：`joinRollGoPerMin.<p>` ＋ 一般熱點來源的 `fightEntriesPerMin.<p>`；方向 `group` 上升、`spread` 下降。若擲骰成功本身到不了 5% ⇒ 不登記、留 design。
- seeds：正式區段是草案 §1.3 表中「C3 複驗（姿態＋集結）」的 **3001–3400**，與 C3-2 是**同一份登記**；**3401–3800 是 C4 的區段，不能借用**。**7401–7800** 只是 C3-3 的重新設計備用（只能用一次）。診斷（§4-B）用 1401–1800，不做通過／失敗宣稱。
- Gate：同 3.2；加平衡初檢的節奏項（`spread` 可能讓團戰更少、比賽更長）。

### 3.4 分時期儀器自檢（C3-2 開跑前必須 commit）

- 〔提案〕工具端新寫程式：每 tick 依 Director 的 `phase(t)` 記到對應桶；exec 類（`exec.{top,mid,bot}Ganks`、`exec.{dragon,baron}Contests`）在 480／960 秒讀快照相減；**不改引擎**。
- 自檢：三桶相加＝整場值（逐場）；對照組逐場可重算；不足 60 秒的時期 ⇒ null（事前寫死的納入規則）。
- 這支儀器同時是 W-3 指標 `seatFightEntriesPerMin.<中路>.early` 的前提（〔事實〕該指標今天不存在）。
