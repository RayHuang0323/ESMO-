### A2. 撤退時求不到安全路線，退回直線穿塔

| | |
|---|---|
| 重現 | 生涯中素質 Seeds 93001–93011：6 場 9 次、5 段。5 段全部是「被兩座敵塔的危險圓包住」，4 段在同一個位置（藍方上路一、二塔之間，約 (71, 185)） |

### B2. safeRoute v3 的 Gank 出發 −6.9%

- 原本的登記判準 FAIL **保留**，沒有改判，也沒有調高任何 Gank 機率。
- 逐次追蹤：`tools/owner_preview/diag_gank_outcome_v23.mjs`，生涯中素質 80 個已用過的 Seeds，v2 對 v3，資料在 `v23_nav_safety/gank/`。出發次數與原批次完全相同（594 → 506）。

| 每次 Gank 出發後 20 秒內 | v2 | v3 | 每場成對差（95% CI） |
|---|---|---|---|
| 有效（擊殺，或接觸且打掉 ≥ 20% 血） | 123 | 121 | −0.03（−0.34 ～ +0.29） |
| 　其中擊殺 | 58 | 54 | −0.05（−0.30 ～ +0.20） |
| 無效 | 471 | 385 | −1.08（−1.76 ～ −0.39） |
| 　其中完全沒接觸 | 424 | 348 | |
| 目標正被塔邊承諾釘住 | 84 | 47 | −0.46（−0.70 ～ −0.22） |
| 　其中有效 | 13 | 6 | |
| 目標殘血（< 50%） | 481 | 398 | |

判斷：**是無效 Gank 減少，不是行為退步。**
- 少掉的 88 次全部落在「無效」。有效 Gank 與擊殺的差都在 0 附近。
- 機制：v2 的缺陷讓對線者殘血、站在敵塔邊乾等。Gank 選路給「殘血」與「壓線」加分，所以會朝這些目標出發，但多半抓不到。v3 讓他們撤退或退回兵線，這類目標變少。
- 限制：這是用已經用過的 Seeds 做的事後診斷，不是獨立驗證。
- v5 的獨立驗證裡，v3 → v5 的 Gank 出發是 +2.6%（CI 含 0），沒有再往下。

另外看到的事（不是這次要修的）：**v2、v3 都有約七成的 Gank 出發後完全沒接觸到目標**（424／594、348／506）。原因是選路偏好殘血目標，而殘血的人本來就在撤退。
